I design, build and ship LLM pipelines and the products around them, owning each system from architecture to production. Before moving into engineering I worked for years as a technology project manager in banking, so I build with delivery, auditability and cost in mind.

## 🛠️ What I Build

- **LLM Orchestration**: provider-agnostic batch pipelines (Anthropic, Gemini, Fireworks, Alibaba DashScope, Ollama) with checkpointed, resumable execution.
- **Agentic QA Systems**: multi-phase critic systems and LangGraph state machines. Every AI-flagged finding is verified verbatim against the source before it is trusted.
- **Production Apps**: a Flutter app on Google Play (BLoC + ServiceLocator, SOLID, DI) and a multi-tenant SaaS (FastAPI, React, PostgreSQL).
- **MCP Tooling**: a Kotlin MCP server for Google Play Console releases (`deploy_app`, `promote_release`, `update_release_notes`, `get_releases`). Writes are dry-run unless `confirm=true`, and production is draft-only.
- **Agent Governance**: mission-brief delegation, reviewer skill patterns and guardrails for AI coding agents, with every PR reviewed before merge.

## 🧭 Engineering Principles

> **"Do it right the first time — Zero tech debt — Develop once, implement multiple times with shared logic."**

Every contributor and automated agent is expected to align with these foundational tenets:

### 🏛️ Architecture & Simplicity
* **SOLID-Focused:** One responsibility per module, with dependencies injected and decoupled via abstractions.
* **The Simplest Design That Works:** Avoid over-engineering; build precisely what is needed with maximum clarity.

### 🧪 Quality & Verification
* **Test-Driven Development (TDD):** Every change starts with a test that fails for the right reason (red), followed by the minimal fix to pass (green).
* **Gatekeeper CI:** All checks and CI pipelines must be completely green before merging into main.

### 🤖 AI & Automation Governance
* **Transparent LLM Pipelines:** Built-in audit trails and cost estimates (dry-run mode) are mandatory for every LLM operation.
* **Zero Self-Review:** An AI agent never reviews its own code; independent review skills, strict guidelines, and guardrails govern every AI-assisted change.
